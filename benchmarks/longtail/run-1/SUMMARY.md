## 4b. The axis that actually costs — prewarm DURATION, not prewarm bytes

An equal FILE-BYTE budget is not an equal-time budget. A strategy that picks many small
files pays far more prefetch wall-clock than one that picks few large ones at the same byte
count, and admission is gated by prefetch completion. Every cell is listed here sorted by what
it actually cost in time, so matched-duration pairs can be read off directly.
